# ShambhoMART — Free Static E-commerce Website

A responsive, premium blue/white/yellow storefront designed for ShambhoMART.

## Included
- Responsive home page
- Category filtering
- Product cards
- Selection/cart drawer
- WhatsApp enquiry/order flow
- No fixed product prices
- No paid backend required
- Works as a static site on GitHub Pages or Cloudflare Pages

## Important
Replace the demo product data and emoji placeholders in `app.js` with your actual product names, categories and original product images.

WhatsApp number is configured as: +91 74981 69710.

## Free hosting
Recommended:
1. GitHub Pages — available with GitHub Free for public repositories.
2. Cloudflare Pages — static HTML can be deployed directly and is available on Cloudflare plans.

No paid hosting/server is required for this version.
